# Screenshot paste guide

Drop your real screenshots here and reference them from any page with:

```html
<img src="images/YOUR-FILE.png" alt="..." style="max-width: 100%; border-radius: 8px;">
```

Recommended names & where to use them:

| File | Used in | What to capture |
|------|---------|-----------------|
| `hero-device.jpg` | `index.md`, `README.md` | Device on a study desk (hero shot) |
| `tuya-dp-list.png` | `dp-schema.md` | Tuya Platform → product → Data Points tab, DPs filled |
| `panel-home.png` | `dp-schema.md`, `panel-setup.md` | App panel screen: Volume / Mode / Focus Timer / Mute / LED / Study Mode |
| `panel-editor.png` | `panel-setup.md` | TuyaOpen IDE → Panel → page editor canvas |
| `mute-config-1.png` | `panel-setup.md` | Mute component: Interaction → Click → Mute → Target "Not" |
| `mute-config-2.png` | `panel-setup.md` | Mute style linkage: on/off color rules |
| `brain-settings.png` | `agent.md`, `agent-prompt.md` | IDE → AI Agent → Brain → Study Assist Brain settings |
| `audio-ai-flow.png` | `architecture.md` | Mic → knock → AI agent → TTS → speaker diagram |
| `flash-gui.png` | `build-flash.md` | tyutool GUI flash dialog (success) |
| `boot-log.png` | `build-flash.md` | Serial monitor, clean boot log |

> Tip: PNG screenshots of the Tuya Platform / IDE / app look sharp on both light and
> dark GitHub Pages themes. Keep them under ~1 MB each.
